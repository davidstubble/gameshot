# GameShot Cropper — implementation plan

## Product
A local-first iOS and Android batch cropper using the initialized React Native / Expo Router / TypeScript / NativeWind starter. No account is needed to crop; selected images stay on the device and are never uploaded for processing.

### Crop studio
- **Pro preset**, selected by default: width **3350**, height **1700**, X **1488**, Y **570**, in source-image pixels. It is deliberately not scaled when the source resolution differs.
- **Custom pixels**: editable positive integer width and height, nonnegative integer X and Y; optional centering. Export exactly the specified dimensions, without stretching or upscaling. Reject/skip images whose crop would exceed their bounds, rather than silently clipping the preset.
- **Aspect ratio**: common ratios 16:9, 9:16, 1:1, 4:3, 3:2 plus editable ratio width and height (including decimals). Use the largest fitting crop for each image, anchored centrally by default. Ratio crops retain source resolution rather than resizing to an arbitrary output size.
- **Interactive preview**: source image with accurately mapped crop overlay and visible source/output dimensions. Custom crop boxes can be dragged; aspect-ratio crop boxes can be resized with a handle while maintaining the ratio. Exact-pixel dimensions stay fixed when dragging. The Pro preset remains locked. Position in aspect-ratio batches maps proportionally to each source's available travel space.
- Multi-image selection, a navigable thumbnail queue, remove/add controls, and clear explanations when settings or images are invalid.

### Processing and export
- Use Expo Image Manipulator for native crops, image/file picking for imports, FileSystem for private local copies, and sharing for exports. Browser preview uses an isolated browser canvas adapter and a ZIP download so the workflow can be tried on desktop too.
- Decode/process images sequentially, not the whole batch at once; display progress and allow cancellation between files. Failures are reported per image without hiding successful outputs.
- PNG output by default, JPEG optional. Output extensions match encoded data. Names preserve the original basename and add a crop suffix; unique batch directories prevent overwriting existing exports.
- Native results live in a dedicated app-private `GameShot/cropped/<batch>/` directory, separate from the phone gallery originals. Users can share a ZIP to Files or other apps, or explicitly save new copies to the gallery (subject to system permission). No assumption that arbitrary original-file parent directories are writable on iOS/Android.
- Browser export downloads a ZIP containing the output copies in a `cropped/` folder. A gallery operation is not offered on web.
- Results screen shows actual successful exports, errors, dimensions and export actions. Current-session output history is in memory; no false promise of persistent gallery management.

## Serving and dependencies

### Posting-order update
Keep the picker-provided import sequence and append later additions without sorting by filename or date. Stamp each processed result with its one-based queue position. Name new copies `0001_original-name_cropped.png`, using at least four prefix digits and a consistent width across the full batch. This preserves order when file managers sort by name and keeps gaps for failed sources rather than silently moving a later source into an earlier slot. Centralize output ordering for result rows and ZIP entries; legacy in-session outputs without sequence metadata retain their existing array order. Native gallery saves run last-to-first so newest-first photo pickers are more likely to show the first imported image first. Do not falsify source timestamps or promise control over another app's sorting. Add no sharing/permission dependency for this update.

## Structure
- `app/(tabs)/index.tsx`: portrait crop studio.
- `app/(tabs)/exports.tsx`: current-session exports and error summaries.
- `components/crop/`: visual preview, numeric controls and queue components.
- `lib/crop/geometry.ts`: pure source-pixel geometry, validation, drag mapping and aspect-ratio math.
- `lib/crop/types.ts`: shared settings, source images and export result types.
- `lib/crop/platform.native.ts` / `.web.ts`: separate import, crop and export implementations.
- `lib/crop/store.tsx`: session state, sequential batch lifecycle and cancellation.
- `tests/crop.test.ts`: focused geometry and batch behavior coverage.
- `assets/images/`: distinct launcher, splash and favicon assets.

## Design
- **Movement:** precision-tool minimalism, combining a dark photographic workspace with Swiss editorial hierarchy.
- **Principles:** image-first, pixel-exact, quietly technical, thumb-friendly.
- **Color philosophy:** charcoal/ink grounds the image; warm white gives labels contrast; electric lime marks only selections, crop outlines and primary actions. Muted gray separates supporting information.
- **Layout:** a compact branded header, a wide image stage, a horizontal queue, a segmented mode selector and stacked settings, with a persistent lower action area. Wide web layouts retain a bounded workspace and pair preview with settings instead of stretching phone controls across the page.
- **Signature elements:** a four-corner crop-bracket logo, lime frame corners with thirds guides, monospace dimension readouts and small numbered workflow labels.
- **Interaction:** direct manipulation with bounded dragging; selected controls have an obvious border/fill; disabled and invalid states explain why. Native taps can use light haptics. Keep important actions at least 44px tall.
- **Animation:** restrained 150–200ms fades and button feedback; no animation of crop coordinates that could obscure precision. Progress advances according to completed files, not synthetic timing.
- **Typography:** platform sans-serif for readable UI (SF Pro/Roboto; system sans on web), paired with platform monospace (Menlo/monospace) for pixels and ratios. Large semibold title, 14–16px controls, 11–12px metadata.
- **Brand essence:** “The precise batch cropper for screenshots worth sharing.” Precise, focused, confident.
- **Voice:** plain and useful: “Your shot. Just the good part.” and “Crop 8 images.” Avoid overstating readiness or performance.
- **Wordmark/logo:** tightly set GameShot wordmark paired with a distinctive four-corner frame enclosing a small focal point; no gaming trademark imagery.
- **Signature color:** electric lime `#C5F76F`.
