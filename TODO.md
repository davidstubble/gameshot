# GameShot Cropper

- [x] **Pixel-exact modes.** Default Pro preset is width 3350, height 1700, X 1488, Y 570, locked and never scaled. Custom pixels accept positive integer width/height and nonnegative integer offsets, with optional centering. Output uses those exact pixels without upscaling; out-of-bounds sources are reported/skipped rather than silently clipped.
- [x] **Aspect-ratio mode and interactive preview.** Offer 16:9, 9:16, 1:1, 4:3, 3:2 and user-entered positive ratios including decimals. Largest fitting source-resolution crop by default. Overlay accurately maps source pixels, shows dimensions, permits custom dragging and ratio-locked resizing, and keeps the Pro preset fixed. Aspect positioning maps proportionally across batch sizes.
- [x] **Multi-image queue and batch lifecycle.** Import multiple images, navigate previews, add/remove sources, explain invalid inputs, process sequentially with real progress, allow cancel between files, and preserve successful results when another file fails.
- [x] **Non-destructive exports.** PNG default and optional JPEG with matching extensions. Preserve source basename plus crop suffix and sequence prefix; unique app-private GameShot/cropped batch directories on native. Share ZIP to Files/other apps; optional permission-gated gallery copies. Browser downloads ZIP with cropped folder. Never modify source/gallery originals.
- [ ] **Results and branded mobile delivery.** Show current-session successes, errors and dimensions with functional export actions. Dark, lime-accented portrait workspace and distinct launcher/splash/favicon assets. Preserve starter runtime adapters, app slug/scheme/identifiers and fixed 8081/3000 listeners. Deliver tested preview and accepted source checkpoint; disclose native device/build gaps.
- [x] **Postable import order.** Files must keep the same order in which they came into the app, including later additions. Preserve that order through processing, result rows and ZIP entries. Prefix cropped-copy filenames with consistently padded sequence numbers before the original basename so filename sorting also preserves import order, including batches above 9 or 99 files. Skipped/failed sources must not reorder successful files; originals remain unchanged. Show sequence numbers in Exports. Save gallery copies last-to-first to accommodate newest-first photo pickers, and explain that another app can still apply its own sorting.
